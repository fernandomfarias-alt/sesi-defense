# 🎮 SESI DEFENSE - Multiplayer Tower Defense Game

A commercial-quality cooperative tower defense game inspired by Roblox TD, Bloons TD, and Dungeon Defenders with a unique SESI/SENAI school theme.

## 🎯 Game Concept

The school has fallen into chaos. Teachers, monitors, guards, and corrupted staff members are invading. Students must defend the last surviving communication system: **A CELL PHONE BASE**.
